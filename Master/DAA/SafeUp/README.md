# SafeUp

SafeUp is a platform that allows users to purchase device warranties and manage this subscriptions. It provides an easy way to protect your devices with just a few clicks.

## Tech Stack

- **Backend**: .NET Core (API)
- **Frontend**: Angular
- **Database**: SQL Server (or your preferred database)

## Getting Started

### Backend

1. Navigate to `/SafeUp.Api`
2. Run `dotnet restore` to install dependencies.
3. Run `dotnet run` to start the backend.

### Frontend

1. Navigate to `/SafeUp.Web`
2. Run `npm install` to install dependencies.
3. Run `ng serve` to start the frontend.
