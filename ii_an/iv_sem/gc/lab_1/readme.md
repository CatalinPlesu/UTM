# Crearea unei scene grafice statică 2D.

Idei:

1. Fractali
2. Scena cu coordonate si miscarea camerii
3. Generare de teren 2D

Fianl:
 - am implementat setul lui mandlebrot cu posibilitatea de a face zoom 
   
Evenimente:
```
WASD -  miscarea camerei
QE -  zoom out, in
RF - +iteratii-
ENTER - save
```
