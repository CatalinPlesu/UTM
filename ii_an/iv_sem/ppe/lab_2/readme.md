Tema: Interfaţa GDI

Obiective:
- studierea primitivelor oferite de interfaţa GDI;
- studierea și utilizarea a apelurilor de funcţii GDI;
- enumerarea metodelor de obţinere a variabilei handle a dispozitivului de
  context;
- crearea unui program simplu.

Sarcina:  Scrieţi un program care afişează în zona client un desen animat,
utilizând toate primitivele GDI.

Primitive:
- Linii şi curbe
- Suprafeţe pline
- Imagini bitmap
- Text
